# React + TypeScript + Vite + shadcn/ui + TanStack

This is a template for a new Vite project with React, TypeScript, shadcn/ui, and TanStack.

## Getting started

Run `bun install` to install dependencies.

Run `bun dev` to start the dev server.

Build with `bun run build`.
